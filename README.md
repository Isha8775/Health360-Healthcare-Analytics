# Health360-Healthcare-Analytics
Healthcare Risk and Disease Analytics using Tableau

## Project Overview
Health360 is a healthcare analytics project focused on exploring patient demographics, clinical indicators, and lifestyle factors associated with heart disease, diabetes, and stroke.

## Objectives
- Explore and clean healthcare datasets.
- Analyze disease patterns and risk factors.
- Build interactive dashboards using Tableau.
- Present insights through a Tableau Story.
- Document testing, findings, and project implementation.

## Tools & Technologies
- Python and Pandas
- Tableau Public
- GitHub
- Flask (for dashboard embedding, if required)

## Project Structure
- `data/` — Original dataset
- `cleaned_data/` — Cleaned dataset
- `tableau/` — Tableau workbook and dashboards
- `flask_app/` — Web application files
- `documentation/` — Report, screenshots, and testing results

In progress.
